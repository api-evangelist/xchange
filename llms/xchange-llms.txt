# Container xChange

> Container xChange (xChange, container-xchange.com) is a Hamburg-founded B2B
> online marketplace and operating platform for shipping containers, where
> container owners, users, traders, and lessors buy, sell, and lease standard
> and special containers worldwide. The platform covers container trading, one-way
> and long-term leasing, payment handling (xChange Wallet), insurance, container
> tracking/control, and market-price insights, with a live North America container
> inventory storefront. Backed by Point Nine among other investors.

Container xChange does not publish a public developer API, developer portal, or
machine-readable API specification. Its "xChange Connect" integrations (customer
supply-listing feeds and depot container-movement reporting) accept data via API
or spreadsheet, but onboarding is arranged privately through an account manager
or service@container-xchange.com — no public API documentation exists.
